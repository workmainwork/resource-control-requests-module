# Информационная система планирования и контроля ресурсов организации

Модуль предназначен для стандартизации внутренних обращений сотрудников и контроля сроков их рассмотрения. Пользователь может создать заявку, указать тип, приоритет, желаемый срок исполнения, ориентировочную стоимость и описание. Руководитель получает инструмент для просмотра карточки заявки, рассмотрения обращения и фиксации решения.

## Реализованные функции

- создание новой заявки;
- автоматический расчёт SLA в зависимости от приоритета;
- просмотр списка заявок;
- получение карточки заявки;
- согласование, отклонение или перевод заявки в работу;
- фиксация комментария руководителя;
- подготовка основы для дальнейшего расширения под уведомления, бюджетный контроль и журналирование.

## Структура проекта

```text
routes/
    employee.py             # маршруты сотрудника: создание и просмотр заявок
    manager.py              # маршруты руководителя: карточка и рассмотрение заявки
services/
    request_service.py      # бизнес-логика модуля управления заявками
tests/
    conftest.py             # фикстуры для тестов
    test_request_service.py # unit-тесты сервисного слоя
    test_request_routes.py  # интеграционные тесты маршрутов
app.py                      # точка входа Flask-приложения
config.py                   # конфигурация проекта
models.py                   # модель Request и подключение SQLAlchemy
seed.py                     # заполнение базы демонстрационными данными
requirements.txt            # зависимости проекта
README.md                   # инструкция по сборке и запуску
```

## Стек технологий

- Python 3.11+
- Flask
- Flask-SQLAlchemy
- SQLite
- pytest
- pytest-cov

## Сборка и запуск проекта

### Создание виртуального окружения

#### Windows (PowerShell)

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Инициализация базы данных и загрузка тестовых данных

```bash
python seed.py
```

### Запуск приложения

```bash
python app.py
```

После запуска приложение будет доступно по адресу:

```text
http://127.0.0.1:5000/
```
## Запуск тестов

```bash
pytest -v
```

## Получение отчёта по покрытию кода

```bash
pytest --cov=services.request_service --cov=routes --cov=models --cov-report=term-missing
```
